1. 従来のAIと何が違うのか

ChatGPT、Gemini、普通のClaude — どれも「便利な他人」です。
聞けば答えてくれる。でもあなたのことは何も知らない。毎回ゼロから。

従来のチャットAI
月曜「資料作って」
→
ゼロから説明
火曜「続きやって」
→
「何の続きですか？」
水曜「前と同じ形式で」
→
「どの形式ですか？」

Claude Code は違います。フォルダにファイルを置くだけで、記憶・性格・ルールを持てる。
使えば使うほど、あなたの仕事のやり方を覚えていく。

Claude Code（このキット導入後）
月曜「資料作って」
→
あなた好みの形式で即作成
火曜「続きやって」
→
「昨日のA社の件ですね」
水曜「これどう思う？」
→
過去の失敗踏まえた提案

あなたにとって何が変わるか：

・毎回の説明が消える → 時間が浮く
・ダメ出しが蓄積する → 同じミスが消える
・好みを覚える → 出力の精度が上がり続ける
・タスクの進捗を覚える → 「どこまでやったっけ？」が消える

2. フォルダ = AIの脳

じゃあどうやって記憶させるのか？答えはシンプル。フォルダにファイルを置くだけ。

Claude Codeは、起動したフォルダの中にあるファイルを全部読めます。
逆に言えば、フォルダの外にあるファイルは読めません。

起動するフォルダでAIの脳が変わる
デスクトップで起動ファイル何もなし
↓
何も知らないAI毎回「はじめまして」
VS
このキットで起動CLAUDE.md + mind.md + memory.md
↓
あなた専用のAIルール・性格・記憶つき

フォルダの中にファイルがある = AIに脳がある。
フォルダが空 = 脳が空。

特に重要なのが CLAUDE.md というファイル。
Claude Code は起動時にこれを自動で読んで、書いてあることをルールとして守ります。
新しいスタッフに渡す業務マニュアルと同じ。ただしAIは毎回完璧に読む。

3. 「会社」として考える

ここが一番大事な考え方です。

普通のAIチャットは「1人の賢い人に聞く」感覚。
Claude Code は違う。「自分の会社を作る」感覚です。

AIを「会社」として考える
CLAUDE.md = 会社の定款全社ルール。「うちの会社はこう動く」
↓
roles/ = 社員最初は1人（assistant）から始まる
↓
mind.mdこの社員の性格
memory.mdこの社員の業務日報
↓
knowledge/ = 社内マニュアル全員が参照する確定知識

最初は社員1人（assistant）で十分。慣れたら増やせます。
例えば「データ分析専門」「マーケティング専門」のように、役割ごとにロールを分けると、それぞれが専門性を持って育つ。

ロールが分かれてると何が嬉しいか：

1人に全部やらせると、記憶がごちゃ混ぜになる。
「データ分析の知識」と「営業トークの知識」は別の脳に入れた方がいい。
人間の会社と同じ。専門分化した方が強い。

でも最初は1人でOK。「もう1人欲しいな」と思った時に増やせばいい。

4. 3つの記憶 — mind / memory / knowledge

このキットには3種類の「記憶ファイル」があります。
全部「AIの記憶」なんだけど、役割が全然違う。

3つの記憶の関係
mind.md = 性格「お前はこういうやつだ」
↓ ダメ出しで育つ
memory.md = 日記「昨日こんなことがあった」
↓ 3回出たら昇格
knowledge/ = 教科書「これは確定事実」

mind.md — 性格

「簡潔に話せ」「忖度するな」「データで語れ」— こういう行動原則が入る。

あなた
長い。結論だけ先に言って
→ mind.md に「結論ファーストで話せ」が追記される
あなた
毎回聞くな。自分で判断して
→ mind.md に「判断を投げるな。自分で決めろ」が追記される

変わるもの：AIの話し方、判断基準、仕事のスタイル
いつ変わる：あなたがダメ出しした時
頻度：最初は週に数個。1ヶ月で15個くらいに成長

memory.md — 日記

「A社の担当は田中さん」「この資料は先週の会議で使った」— 事実と進捗が入る。

あなた
ここまで
→ memory.md に今日やったこと、学んだこと、次やることが記録される
あなた（翌日）
おはよう
AI
おはようございます。昨日のA社提案書の続き、修正点3箇所ありましたよね。そこからやりますか？

変わるもの：AIが覚えてる事実、進捗、文脈
いつ変わる：「ここまで」と言った時に自動記録
頻度：毎セッション

knowledge/ — 教科書

memory.md（日記）に何度も同じことが出てきたら、もう「確定知識」。

memory.md に3回「タイトル変更後は2週間待て」が出た
→ knowledge/tips.md に自動昇格
→ 二度と忘れない。新しいセッションでも最初から知ってる

変わるもの：AIの「常識」。永久に残る確定知識
いつ変わる：同じパターンが3回出た時に自動昇格
頻度：週に1〜2件。ゆっくり確実に育つ

まとめると：

mind.md = 「こういう性格でいろ」 → ダメ出しで育つ
memory.md = 「これ覚えとけ」 → 毎セッション自動記録
knowledge/ = 「これは常識だぞ」 → 3回出たら自動昇格

5. 全ファイル解説

フォルダ構造

my-project/ ← 好きな名前に変えてOK
├── CLAUDE.md ← AIの業務マニュアル
├── ai-export-prompt.md ← 別AIから引き継ぐ時に使う
├── roles/
│   └── assistant/
│       ├── mind.md ← AIの性格・行動原則
│       └── memory.md ← AIの記憶（自動で育つ）
├── knowledge/ ← 長期記憶（自動で育つ）
├── files/ ← 画像・参考資料の置き場
└── .claude/
    └── skills/ ← 自動で動くスキル4つ
        ├── setup/ ← 初回セットアップ
        ├── session-wrap/ ← セッション終了時の記録
        ├── task-log/ ← 緊急セーブ
        └── status/ ← 成長度チェック

各ファイル詳細

1つずつ解説します。まず全体の関係図から。

ファイルの関係 — 3つの層
CLAUDE.md憲法 — 全体のルール。触らなくてOK
↓ 読み込む
mind.md性格 — /setupで自動生成。育つ
memory.md日記 — 毎回自動で追記。育つ
↓ 3回出たら昇格
knowledge/教科書 — 確定した知識。永久保存
CLAUDE.md
AIの憲法 — 「この会社ではこう働け」
Claude Codeが起動すると最初に自動で読むファイル。ここに書いたことは毎回守られる。

中身は3つ：
  • 初回起動ルール： mind.mdがまだ未設定なら /setup を自動実行
  • セッション開始ルール： 毎回 memory.md と knowledge/ を読んでから仕事開始
  • メモ魔ルール： 「ダメ出しされたら即記録」「事実を教わったら即記録」等、AIが自分で判断して記録するルール
あなたは触らなくてOK。仕組みの土台として最初から完成してる。
roles/assistant/mind.md
AIの性格 — 「お前はこういうやつだ」
「簡潔に話せ」「忖度するな」「データで語れ」— こういう行動原則が入る場所。

手書き不要。初回の /setup で4つの質問に答えるだけで自動生成。
その後は使い続けるだけで育つ。あなたが「それ違う」と言うたびに、新しい原則が追記される。

1日目は3個。1ヶ月後には15個。それが「あなた専用のAI」の正体。
roles/assistant/memory.md
AIの日記 — 「昨日こんなことがあった」
このキットの核心。空の状態からスタート。

あなたが普通に会話するだけで、AIが自分で判断してここに書き込む：
  • 教えてもらった事実（「担当は田中さん」「納期は来週金曜」）
  • ダメ出しされたこと（「長い」→ 次から簡潔に）
  • タスクの進捗（何が終わって、次に何をすべきか）
特別なコマンドは不要。AIが会話の中で「これは記録すべき」と判断したら勝手に書く。
次回起動時に自動で読む → だから「前回の続き」から始まる。
knowledge/
AIの教科書 — 「これは確定事実」
memory.md（日記）は日々流れていく。でも何度も出てくるパターンは「もう確定でしょ」。

同じことが3回出たら、AIが自動でここに移す。
例：mistakes.md（やったらダメなこと集）、tips.md（これやると効くリスト）。

日記→教科書への自動昇格。一度教科書に載ったら二度と忘れない。
files/
共有フォルダ — 「これ見て」の置き場
VS Codeのチャットでは画像を直接貼り付けできない。
スクリーンショットやPDF等をここに入れて、「files/の画像見て」と言うだけ。
ai-export-prompt.md
引き継ぎ書 — 「前のAIで育てたもの、持ってきて」
ChatGPTやGeminiを使い込んでる人向け。
中にプロンプトが入ってる → それを今のAIに貼る → あなたの好み・ルールをまとめてくれる → その出力を /setup に食わせる。
ゼロからやり直す必要がなくなる。使ってない人はスキップOK。

スキル（.claude/skills/）

スキルは「特定の言葉を言うと自動で動くプログラム」です。手動で呼び出す必要はありません。

/setup
初回セットアップ
いつ動く： 初めてClaude Codeを起動した時に自動で始まる
何をする： 4つの質問であなたの仕事・好み・ルールを聞いて、mind.md を自動生成する
所要時間： 5分
/session-wrap
振り返り（任意）
いつ動く： 「まとめて」「振り返り」と言った時
何をする： セッション全体を振り返って、記録漏れがないかチェック + knowledge/昇格判定
普段の記録は自動。これは「ちゃんと振り返りたい時」のオプション。使わなくても記憶は溜まる。
/task-log
緊急セーブ（任意）
いつ動く： 「中断」「セーブ」と言った時
何をする： 今やってることと再開手順だけを素早く記録する
急に止めなきゃいけない時用。普段は自動記録されてるから不要。
/status
成長度チェック
いつ動く： 「/status」「育ち具合」と言った時
何をする： 行動原則の数、記憶の件数、レベル（Lv.1新人 → Lv.5右腕）を表示
育ってる実感が持てる。

6. 使い始め方

1 フォルダ名を変える

my-project を自分の仕事の名前に変える。
例：sales-ops、accounting、blog-management

2 Claude Code を起動する

そのフォルダの中で Claude Code を開く。
mind.md がまだ未設定なので、/setup が自動で始まる。

3 4つの質問に答える

AIがこう聞いてくる：

AI
4つだけ教えてください。

① お仕事は？ Claudeに何を手伝って欲しいですか？
② AIにイラッとしたことは？ これが一番大事です。
③ どんな感じで話して欲しい？ 丁寧 / フランク / 簡潔 / 壁打ち
④ これだけは絶対やるなってことある？

答えるだけで mind.md が自動生成される。手書き不要。

② が一番大事な理由：

「長い」「聞いてばっかり」「毎回忘れる」— あなたの不満は、あなたの「AIはこうあるべき」の裏返し。
これが mind.md の行動原則（AIの性格）に変換される。

4 普通に仕事する

いつも通り何でもOK。特別なコマンドも合言葉も不要。
会話の中でAIが自分で判断して、大事なことをmemory.mdに記録していく。
次に起動した時、前回の続きから始まる。

あなたがやることは：普通に仕事するだけ。

ダメ出しすれば性格が育つ。事実を教えれば記憶が増える。
全部自動。覚えることゼロ。

7. AIが育つ話し方

特別なことは何もない。思ったことをそのまま言うだけ。
ただし、言い方によって育ち方が変わる。

ダメ出しする → 行動原則が増える

AI
分析結果をまとめました。まず市場動向から説明すると...
あなた
長い。結論だけ先に言って
→ mind.md に「結論ファーストで話せ」が追記される

「覚えておいて」と言う → 即記録される

あなた
覚えておいて、A社の担当は田中さん。メールより電話が好き
→ memory.md に即記録。次にA社の話が出たら自動で反映

理由を添える → 深い学びになる

あなた
この提案ダメ。うちの業界ではそのやり方は法的にアウトだから
→ 「なぜダメか」が knowledge/ に記録される。二度と同じ提案をしない

「いいね」も言う → 刺さったポイントが記録される

あなた
この表形式いいね。次からもこの形式で出して
→ 好みのフォーマットが記録される。次回から同じ形式で出してくる

育たない話し方：

「うーん、まあいいか...」
→ 何も記録されない。違和感があったら遠慮なく言う。ダメ出しは最高の教育。

基本思想：

リアルで自分が会社のオーナーになるのと同じ。
初日から完璧な会社になるわけない。
最初は「こいつら使えないな…」でいい。

やらせたいこと、やらせたくないこと。あなたの哲学を浸透させていく。
ダメ出しの数だけ、AIは強くなる。

8. 育った先の姿

1日目

/setup が完了。mind.md に行動原則が3〜5個。memory.md は空。
まだ何も知らない新人。でも「あなた好みの話し方」は最初からできる。

1週間後

memory.md に記録が溜まり始める。
「前回ここまでやりましたよね」「A社の田中さんですね」が自動で出てくる。
同じ説明を2回する必要がなくなる。

1ヶ月後

mind.md の行動原則が10個を超える。knowledge/ にファイルが生まれる。
あなたの仕事の癖、好み、NG を全部知ってるアシスタントが完成する。
「おはよう」と言うだけで、今日やるべきことを提案してくる。

最初から完璧にする必要はありません。

フォルダを置いて、普通に使って、「ここまで」と言う。
それだけで、AIは勝手に育ちます。
